# Code of Conduct

Be kind and respectful. No harassment, insults or discrimination, in issues, pull requests or anywhere else the project is discussed. Keep feedback about the work, not the person.

Maintainers may remove comments and block people who break this. To report a problem, use the [private report form](https://github.com/sailxx/Tobi/security/advisories/new).

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
